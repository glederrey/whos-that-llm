# Who's that LLM

A guessing game in the spirit of Who's that Pokémon. A hidden language model answers in a chat. The player has five messages, and one guess after each reply, to name the model. The right company or the right family still counts. The exact model is the win.

Nobody is told which lab is speaking. The fun is the voice: short replies, a small set of suspects, and the moment the name is revealed. It is a game for people who already talk to these models and argue about how they sound.

The game is not built yet. The spec is in [`docs/`](docs/README.md).

Stack, when the code starts: Next.js, Supabase (auth and Postgres), OpenRouter, hosted on Vercel.
