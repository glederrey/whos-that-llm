Recursion is when a thing uses a smaller copy of itself. Like Russian dolls:
  • open a doll,
  • find a smaller doll,
  • stop when the doll is solid.
def open_doll(n):
    if n == 0:
        return "solid!"
    return open_doll(n - 1)
More on base cases if you want.
