# Leaderboard
The ranking table on Home (top 5) and Leaderboard.

**Consumer provides:** rows of rank, player name, avatar, rounds and points; the current player's row id.

- Ranks 1 to 3 use medal chips; the player's own row gets a `hit-wash` band and the `You` tag.
- Numbers are mono and right-aligned. Headers use the mono `label` style.
- On phones the table scrolls sideways rather than wrapping names.
