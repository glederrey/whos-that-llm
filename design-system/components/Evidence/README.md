# Evidence
What the player's wrong guesses have proved about the hidden model: company, origin, year and size, as four tiles.

**Consumer provides:** each trait's name, value and state: `is-hit`, `is-miss` or `is-unknown`.

- Unknown: a dashed `control-line` tile with a `?`. Hit: `hit-wash` with a check and the value in `teal-text`. Miss: `miss-wash` with a cross and the struck-out value in `miss-text`.
- Each state has a shape (dash, check, cross) as well as a color, so it reads without color.
- A hit unveils with a short scale-in (`t-settle`); nothing else moves.
- Two columns at every width; labels are mono uppercase.
